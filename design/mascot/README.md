# bagl mascot

`gen_app_mascot.py` draws bagl (the coral round patch version that's in the app) and writes the SVG, CSS and icon art:

    python3 gen_app_mascot.py <out-dir>

`takes.py` draws the six e-mark takes side by side. To go back to the purple square patch, use the `"purple"` mark from `takes.py` in place of `patch()` in the generator.

`purple-patch-moods.png` and `purple-patch-idle.gif` are the purple-patch version, kept in case we switch back.
